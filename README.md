# 🔥 열공장 타이쿤 (Heat Factory Tycoon)

건축환경 설계 및 제어(ARC2041) 강의 **「02 Thermal Energy and Heat Transfer」**, **「03 Moisture Transfer」**의
공식을 하나씩 **해금**하며 열에너지(J)를 버는 성장형(방치형·클리커) 학습 게임입니다.

▶ 플레이: https://ohan9i.github.io/diff/  (시연용 빠른 모드: `https://ohan9i.github.io/diff/?speed=10`)

## 게임 방법

- **돈 = 열에너지 J**, 초당 수입 = **W (J/s)**. 습기 단계부터는 **💧 물(g)** 이 두 번째 화폐가 됩니다.
- 불꽃이(캐릭터)나 **충전 버튼**을 누르면 열이 집으로 날아가며 돈이 들어옵니다.
- 해금한 **공식 카드**가 자동으로 돈을 법니다. 카드의 변수(k, ΔT, Δx, A, h, ε, μ …)를 업그레이드하면
  공식 그대로 출력이 바뀌어서 어떤 변수가 비례/반비례인지 몸으로 느낄 수 있어요. 직접 계산할 필요는 없습니다.
- 가끔 나타나는 **불덩이**를 집으로 드래그하면 보너스(열은 고온에서 저온으로!).
- 업그레이드할 때마다 카드 속 그림과 방 안 장면이 바로 바뀝니다 (재료 질감 = k, 블록 두께 = Δx, 높이 = A, 불 크기 = ΔT, 막대 수 = N, 대류 방식 = 공기·팬·물·끓음 …). 아직 사지 않은 막대·설비는 보이지 않아요.
- **💡 공식 퀴즈**, **📷 열교 찾기**, **💧 결로 위기(Glaser)** 미니게임이 큰 보상을 줍니다.
- 진행 상황은 브라우저에 자동 저장되고, 자리를 비운 동안에도 절반만큼 벌어요.

## 해금 순서 (공식 = 기계)

| # | 공식 | 게임 속 역할 |
|---|---|---|
| 1 | 푸리에 법칙 q = kΔT/Δx | 첫 수입원. 재료(k), 온도차, 두께, 면적 업그레이드 |
| 2 | 병렬 연결 1/R<sub>t</sub> = Σ1/R | 푸리에 막대를 여러 개 나란히 → 열류가 더해짐 |
| 3 | 직렬 저항 R<sub>t</sub> = ΣR | 배관 단열을 쌓아 배송 효율 η = R<sub>t</sub>/(R<sub>t</sub>+R<sub>0</sub>) 상승 |
| 4 | 뉴턴 냉각 q = h<sub>c</sub>ΔT | 자연대류 → 강제대류 → 액체 → 비등·응축 |
| 5 | 열교 Ψ, f<sub>Rsi</sub> | 숨어 있던 누설 β 를 줄임 + 열화상 열교 찾기 미니게임 |
| 6 | 스테판-볼츠만 q = εσ(T⁴−T<sub>sur</sub>⁴) | T⁴ 의 폭발력 |
| 7 | 상당외기온도 T<sub>sol</sub> | 낮에만 버는 일사 흡수 (60초 = 하루) |
| 8 | 💧 이슬점 응축기 φ, p<sub>sat</sub>, x | 이슬점 아래로 식혀야만 물이 나옴 |
| 9 | Fick 확산 g = δ<sub>0</sub>Δp/(μd) | 물로 업그레이드하는 투습막 |
| 10 | 잠열 회수 h<sub>fg</sub> ≈ 2500 J/g | 물의 흐름을 다시 열(J)로 |
| 11 | Glaser 결로 판정 | 방습층 위치 맞히기 → 전역 배수 +10% |

업그레이드 가격은 "그 업그레이드로 늘어나는 수입 × 회수 시간"으로 정해져서, 물리값의 크기가 크게 달라도
게임 속도가 일정하게 유지됩니다. Glaser 미니게임은 실제 Glaser 계산(온도분포 → p<sub>sat</sub>, s<sub>d</sub> 축 수증기압, 결로량)을 그대로 돌립니다.

## 기술

- React 18 + Vite, Canvas 2D (배경 방·캐릭터·카드 그림 모두 코드로 그림)
- 수식 표시: [KaTeX](https://katex.org) (MIT License)
- `app/src/game/` 물리·경제 모델 (`model.js`, `engine.js` = Glaser 계산), `app/src/scene/` 방·캐릭터·카드 그림, `app/src/App.jsx` 화면
- 빌드 결과(`index.html`, `assets/`)를 저장소 루트에 그대로 두어 GitHub Pages(main / root)로 배포합니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 루트의 index.html, assets/ 갱신
```
