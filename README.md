# 열·습기 전달 시뮬레이터 (Heat & Moisture Transfer Simulator)

건축환경 설계 및 제어(ARC2041) 강의 **「02 Thermal Energy and Heat Transfer」**, **「03 Moisture Transfer」** 내용을
슬라이더로 직접 조작하며 이해할 수 있도록 만든 인터랙티브 웹 시뮬레이터입니다.

설치 없이 브라우저에서 `index.html` 을 열거나, GitHub Pages 주소로 접속하면 됩니다.

## 핵심 아이디어

> 열과 습기는 둘 다 **"차이(포텐셜)"가 있을 때 흐르고, "저항"이 클수록 덜 흐른다.**

| | 열 (Part 1) | 수증기 (Part 2) |
|---|---|---|
| 원동력 | 온도차 ΔT | 수증기압차 Δp |
| 법칙 | 푸리에 q = −k dT/dx | Fick g = −(δ₀/μ) dp/dx |
| 층의 저항 | R = d/k | s<sub>d</sub> = μd |
| 직렬 합산 | R<sub>t</sub> = ΣR, U = 1/R<sub>t</sub> | s<sub>d,t</sub> = Σμd |

## 구성 (16개 화면)

**Part 1 · 열에너지와 열전달**
1. 열부하 vs 에너지 사용량 — 에너지 사용량 = 부하 ÷ 효율, 패시브/액티브 기술
2. 전도 · 푸리에 법칙 — k, 두께, 온도차 조절 + 재료별 등가 두께 비교
3. 다층 벽체 · U값 — 층 편집, 내부 온도 분포, 저항 회로 비유, 병렬 구성 (강의 p.29 예제 내장)
4. 비정상 전도 · 열용량 — 1차원 유한차분 해석으로 하루 외기 변화에 대한 시간지연 확인
5. 대류 · 뉴턴 냉각 법칙 — 자연/강제대류 경계층 애니메이션, h<sub>c</sub>
6. 복사 — 플랑크 분포, 스테판-볼츠만, ρ+α+τ=1, h<sub>r</sub>, 온실효과와 Low-e 유리
7. 상당외기온도 — 하루 동안의 T<sub>sol</sub>, 외벽 색에 따른 열취득
8. 열교 — 벽-발코니 슬래브 접합부 **2차원 정상 열전도 계산 (SOR)**, 등온선·열류, f<sub>Rsi</sub>, Ψ, 곰팡이 위험

**Part 2 · 수분 전달**
1. 물의 상변화 · 잠열 — 가열 곡선, 분자 모형, 체적 열용량 비교
2. 포화수증기압 · 상대습도 · 이슬점 — "컵" 비유, 냉각/가습 애니메이션
3. 습공기선도 — 클릭/드래그로 상태 지정, 냉각·제습 계산 (강의 예제 내장)
4. 증발과 영향 요인 — 면적·온도·습도·풍속
5. 흡습 · 모세관 — 흡착/탈착 히스테리시스, 접촉각과 모세관 상승
6. 수증기 확산 · Fick 법칙 — 강의 예제 1 단계별 계산
7. 내부결로 판정 (Glaser) — 층 편집, s<sub>d</sub> 축 Glaser 선도, 결로량 g<sub>c</sub> 자동 계산 (강의 예제 2 내장)

**정리** — 개념 확인 퀴즈 12문항

## 검증

강의 예제와 결과가 일치하는지 확인했습니다.

- 열 p.29: R<sub>t</sub> = 4.4 m²K/W, q = 6.82 W/m², T<sub>ci</sub> = 37.27 °C, T<sub>iw</sub> = 20.23 °C
- 수분 예제 1: s<sub>d,t</sub> = 10.02 m, q<sub>m</sub> = 4.82×10⁻⁷ kg/s ≈ 41.6 g/day
- 수분 예제 2: s<sub>d,t</sub> = 22.52 m, 경계면 수증기압 321 / 348 / 430 / 921 / 935 Pa, g = 5.45×10⁻⁹ kg/(m²s)
- 습공기 예제: 25 °C 70% → 10 °C, x = 13.9 → 7.6 g/kg (강의는 선도에서 읽은 값 14 → 7.6)
